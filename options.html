Prompt style

Choose what PromptLens should write when you generate a prompt from an image.

IP-safe mode

For contributors to Adobe Stock, Shutterstock, and similar marketplaces that reject images containing third-party IP. When on, PromptLens instructs the model to leave text, brand names, logos, and other recognizable intellectual property out of the generated prompt entirely.

Icon mode

Vision models tend to describe icons like photos — backgrounds, lighting, materials — which produces unusable prompts for icon work. When on, PromptLens first checks whether the image is a UI icon or a bundle/set of icons; if it is, the prompt is written in icon-design language with an explicit solid white background instead. Ordinary photos and scenes are unaffected.
