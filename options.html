Prompt style

IP-safe mode

For contributors to Adobe Stock, Shutterstock, and similar marketplaces that reject images containing third-party IP. When on, PromptLens instructs the model to leave text, brand names, logos, and other recognizable intellectual property out of the generated prompt entirely.

Icon mode

Vision models tend to describe icons like photos — backgrounds, lighting, materials — which produces unusable prompts for icon work. When on, PromptLens first checks whether the image is a UI icon or a bundle/set of icons; if it is, the prompt is written in icon-design language with an explicit solid white background instead. Ordinary photos and scenes are unaffected.

Hover quick-action button

Shows a small floating button over any image as soon as you hover it, so you can generate a prompt with one click instead of opening the right-click menu each time — handy for rapid-fire use across a page full of images. It triggers the exact same generation as the right-click menu item, using whichever provider and style you have set above. Turn it off if you'd rather keep hovering images free of any overlay.

Adobe Stock auto-fill

On the Adobe Stock contributor portal, generates a title and keywords for each uploaded file and fills them in automatically — full auto-pilot across every uploaded file by default. Files that already have a title are always skipped, never overwritten. A generation failure on one file skips just that file and moves on; a rate-limit-type failure automatically retries on the next configured provider first.
